# Solution 網站設計策略

## 參考網站規格

本案以使用者提供的 Inozetek 首頁為**視覺與資訊架構參考**：沉浸式深色汽車影像、細緻緊湊的導覽、醒目的服務分類、產品／服務導向的段落節奏與精品工藝氣質。網站不複製其商標、圖像、影片、具體文字、配色比例或版面細節；Solution 將以自有標誌、繁體中文文案與原創視覺素材建立辨識度。

## 選定方向：精密車藝檔案室

### Design Movement

以**當代汽車編輯設計（Contemporary Automotive Editorial）**結合日系精密工業美學：克制、銳利、重視材質與工序，而非以浮誇特效堆疊奢華感。

### Core Principles

1. **材質先行**：車漆反光、膜料紋理與細部保護是主要視覺主角。
2. **高對比留白**：深色大面積留白與少量銀灰資訊，突顯工藝與層次。
3. **編輯式節奏**：以不對稱畫面、目錄式標籤與超大字級組織閱讀路徑。
4. **可驗證的專業感**：每項服務都以保護目標、施工範圍與預約引導清楚呈現。

### Color Philosophy

石墨黑與近黑色建立安靜、專注的展示空間；霧銀白用於資訊與識別；**鈦金屬綠**只在關鍵導向、狀態標記與光帶細節出現，象徵精密防護與車漆活性，而非將畫面做成高飽和霓虹風。

### Layout Paradigm

採用「**車庫展示廊道**」而非制式置中卡片網格：首頁從全幅車身細節開場，接著交錯排列服務檔案、大幅影像裁切、橫向編號與工藝指標，讓捲動如同沿著一台車逐段檢視。

### Signature Elements

1. **切角框線**：使用細緻的工程式切角邊框標記重點內容。
2. **工序座標**：以 01–04 編號、短橫線與小字標記施工或服務節點。
3. **鈦綠光帶**：只在影像邊緣、按鈕與數字指示採用的低面積辨識色。

### Interaction Philosophy

互動應如檢視鈑件一般直接而有回饋：服務卡片懸停時露出材質細節與行動箭頭；導覽在捲動後轉為具有背景的可讀狀態；服務按鈕會平順帶到對應區段。所有可點擊元素均維持明確焦點與鍵盤可達性。

### Animation

在支援動態效果的裝置上，首頁標題、標籤與服務內容以 30–80ms 的低調錯開節奏淡入並上移；影像僅做極小幅度縮放與遮罩揭露，維持 180–280ms 的加速減速手感。尊重 `prefers-reduced-motion`，並停止所有非必要動態效果。

### Typography System

英文展示字使用 **Barlow Condensed**（600–800）營造汽車銘牌感；繁體中文與內文使用 **Noto Sans TC**（400–700）維持清楚與冷靜。服務名稱使用寬鬆字距的大寫英文輔助；中文標題以粗細對比與緊湊行高建立階層，不使用 Inter。

### Brand Essence

**Solution 是為重視車況細節的車主打造的精密包膜與汽車美容工作室，讓保護性能與個人風格同步完成。**

個性：**精準、克制、俐落**。

### Brand Voice

標題、按鈕與微文案使用短句、具體動詞與工藝詞彙，避免空泛的奢華承諾。

> 「讓每一道反光，都維持剛完成的狀態。」

> 「帶著你的車，從細節開始升級。」

### Wordmark & Logo

使用由斜切方形與連續線條組成的抽象 **S**：如同從車身覆膜裁切線延伸出的符號。文字標誌採緊湊幾何字距，將 `SOLUTION` 作為工作室銘牌，避免預設字型直接拼字。

### Signature Brand Color

**Titanium Signal Green — #A9FF44**：低面積、高識別的鈦金屬綠，僅作為 Solution 的工藝訊號。

## Style Decisions

- 鈦綠色 #A9FF44 不作為整段落背景；僅用於主要動作、編號、勾選、細光帶與工藝定位線。
- 英文展示標題可以保留汽車編輯感，但每一個主要段落都必須搭配繁體中文的工藝內容，清楚提及保護動作、材質狀態、檢視步驟或養護結果。
- 服務區與流程區以不對稱的「檢視廊道」取代均一服務卡片網格；大尺寸裁切影像、檔案編號與工程式細線共同建立沿著鈑件閱讀的節奏。
- 動態效果採「表面檢視儀器」語言：首頁影片中的反光緩慢推移，搭配低頻率掃描線、座標格與段落揭露；動態僅以透明度與位移構成，避免遊戲化或高頻閃爍。
- 背景影片僅在桌面且未要求減少動態效果的情境播放；行動版與減少動態效果模式使用原始主視覺圖片，確保閱讀與載入體驗。
